# html.css.practice

HTML / CSS / JavaScript で作った練習用サイトをまとめたリポジトリです（2025年5月〜）。
各フォルダの `index.html` をブラウザで開くと見られます。

| フォルダ | 内容 | 主な技術 |
|---|---|---|
| [`animate-javascript`](animate-javascript) | ブロックが動くアニメーション | JavaScript, anime.js |
| [`demon-kings-castle`](demon-kings-castle) | 「魔王の城」をテーマにした4ページのサイト | HTML, CSS |
| [`drag-and-drop`](drag-and-drop) | ドラッグ＆ドロップ／Unsplash APIで画像を取得 | JavaScript, fetch |
| [`snow-season`](snow-season) | 雪が降るアニメーション | JavaScript, CSS |
| [`story-games`](story-games) | ストーリーゲーム紹介サイト（メニュー開閉つき） | HTML, CSS, JavaScript |
| [`video-site`](video-site) | 背景動画つきのサイト（メニュー開閉つき） | HTML, CSS, JavaScript |
